# Home Networking and Controls Development Lab

Welcome to the Home Networking and Controls Development Lab! This repository serves as a comprehensive documentation and observability tool for managing and developing a home networking environment.

## Project Overview

This project aims to document the architecture, devices, and observability strategies employed in a home networking lab. It provides insights into how different components interact and how to monitor and log activities within the network.

## Project Structure

- **docs/**: Contains documentation files.
  - **architecture.md**: Details the overall architecture of the home networking lab.
  - **devices.md**: Describes each device in the network, including roles and functionalities.
  - **diagrams/**: Contains visual representations of the network architecture.
    - **network-diagram.svg**: A clickable diagram that links to relevant documentation for each device.

- **observability/**: Contains files related to logging and monitoring.
  - **logging.md**: Outlines the logging strategy, including collection, storage, and analysis of logs.
  - **monitoring.md**: Describes the monitoring tools and techniques used for observing network health and performance.

- **scripts/**: Contains scripts for automation.
  - **collect-logs.sh**: A shell script to automate the collection of logs from various devices.

## Getting Started

To get started with the documentation and observability tools, navigate to the respective directories and explore the files. The clickable network diagram in `docs/diagrams/network-diagram.svg` provides an interactive way to learn about each device in the network.
